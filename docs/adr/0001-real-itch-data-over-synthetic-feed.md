# Real NASDAQ ITCH data instead of a synthetic feed generator

The original brief treated a synthetic binary feed generator as the fallback if ITCH "threatens momentum," reflecting uncertainty about whether real ITCH data was actually obtainable. Research confirmed NASDAQ publishes free ITCH 5.0 sample files (no login required, openly used by public GitHub projects) and that the format, while it has 22 message types, is tractable to parse within a weekend. Real market data exercises genuine market-microstructure edge cases (real price levels, real message volume and ordering) that a synthetic format designed by this project could never faithfully reproduce — so we committed to real ITCH parsing outright, dropping the synthetic-feed fallback rather than carrying it as a hedge.
